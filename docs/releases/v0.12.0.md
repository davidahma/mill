# Mill 0.12.0

This increment fixes aggregate GitHub severity and interrupted artifact
retention. Mixed comments retain their strongest priority. Each verification
attempt keeps its own artifacts, so an interrupted collection can be reconciled
and retried without overwriting earlier evidence. Database open and restore
inspect physical controls. Worker launch rechecks the admitted executable path,
bytes and version.

`init prepare` drafts one outcome and exposes missing decisions without a model
call or authority write. `readiness` discloses context, prerequisites and known
spend. The packaged preparation operations add attended reconciliation and
approved base continuation with cumulative history. Acceptance review remains
distinct from candidate readiness; stable defect identities guide bounded
repair.

`handoff` combines recorded blockers and progress with the next safe operation.
Whole-change evidence and exact consumption manifests retain unknown costs,
human effort and customer qualification. These additions preserve independent
acceptance, exact-candidate review, attended shipping and immutable release
readback. Trusted-host review has not become isolated execution.

The source record precedes publication. Exact build, installed-package,
longitudinal qualification, npm and GitHub readbacks belong to the release
assets. This release does not establish broader stack support or customer
compatibility. Historical task packets, receipts and support evidence remain
intact.
